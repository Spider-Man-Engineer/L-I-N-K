# Contributing to L.I.N.K.

Thanks for your interest in contributing! Here's how to get started.

## Getting Started

1. Fork the repo
2. Clone your fork
3. Create a branch: `git checkout -b my-feature`
4. Make your changes
5. Test locally: `python3 server.py` and `python3 client.py`
6. Commit: `git commit -m "add my feature"`
7. Push: `git push origin my-feature`
8. Open a Pull Request

## Development

Run the server:

```sh
python3 server.py
```

Run a client (in another terminal):

```sh
python3 client.py
```

## Code Style

- Python 3, no external dependencies
- Keep it simple — this is a lightweight tool
- Use clear variable names
- Add error handling where it makes sense

## Bug Reports

Open an issue with:
- What you expected
- What actually happened
- Steps to reproduce

## Feature Requests

Open an issue describing:
- What you want
- Why it would be useful
- How it should work
